# multi-org

Basic MERN Stack setup with **Frontend** (React + Vite) and **Backend** (Node.js + Express).

---

## 📁 Project Structure

```text
multi-org/
├── .gitignore
├── README.md
├── frontend/        # React + Vite
└── backend/         # Express + Node.js
```

---

## 🚀 How to Run

### 1. Backend
```bash
cd backend
npm install
npm run dev
```
Backend runs on `http://localhost:5000`.

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on `http://localhost:5173`.
